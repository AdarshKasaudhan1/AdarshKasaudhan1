🎓 **BCA (Artificial Intelligence & Machine Learning)** undergraduate at **Alliance University, Bengaluru**.

- 🌐 **Full-Stack Engineering:** Developing end-to-end applications with React, Flask, JavaScript, and modern database architectures.
- 👁️ **Computer Vision & NLP:** Hands-on experience with multimodal spam classification, OCR integration, and civic hazard detection.
- 🚀 **Philosophy:** Passionate about converting theoretical ML models into production-ready software tools that solve tangible problems.
